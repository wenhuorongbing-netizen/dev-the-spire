# Core/Integrations/RitsuLib

RitsuLib bootstrap integration lives here.

Historical loader proof used StS2 v0.106.1 with the RitsuLib runtime
variant 0.106.1. The current local game install is v0.107.0, and
official RitsuLib v0.4.24 with lib/0.107.0 is installed. The repo now
compiles against `STS2.RitsuLib` 0.4.24, and the Spire Plus manifest
requires `STS2-RitsuLib` 0.4.24 or newer for the beta.87 package line.
Fresh beta.87 AdditiveBatch1 loader proof is retained under
`.tools/runtime-evidence/v01070-beta87-additive-batch1-direct-20260618-152531/`.

See `docs/integrations/ritsulib.md` for the full staging record and
migration plan.

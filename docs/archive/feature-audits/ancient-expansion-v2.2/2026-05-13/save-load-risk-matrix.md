# Save/Load Risk Matrix

Reviewed source baseline: `a2183ee`.

Local source finding: `SavedProperties` are proven for `AbstractModel`-based serialized models such as cards/relics. `SerializablePlayer` and `SerializableExtraPlayerFields` showed fixed player fields and did not show a general saved-properties carrier for `Player`. Therefore `SavedSpireField<Player,string>` state must be treated as not source-proven until a live save/load test or deeper source proof shows it persists. Urda and Morvi now mirror encoded Player state onto card-backed deck markers through `AncientPlayerState`, and recovery now only reads owned, non-removed deck cards. This prevents stale removed/foreign card markers from reviving state, but still needs live save/load proof.

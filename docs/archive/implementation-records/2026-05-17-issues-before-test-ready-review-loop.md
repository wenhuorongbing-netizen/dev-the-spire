### Source review actionable additions, 2026-05-17

These items are extracted from `docs/review.md` where the review found concrete implementation or verification details that should stay visible in the issue index.

- `MORVI-OVERDUE-LIBRARY-CRASH`: draw archive page must use `CardsVar` or otherwise read the named `IntVar` safely; Strength/Dexterity archive page variables and localization placeholders must use matching keys; `MorviBraveryPagePower` and `MorviDexterityPagePower` need explicit valid icon paths. Add source tests for variable/placeholder consistency and manual tests for all three archive pages.
- `URDA-SEED-BANK-INTERACTIVE-RELIC`: remove Boss-entry `BeforeRoomEntered` blocking card selection from the settlement path. Seed Bank needs a visible stored-card hover, a player-triggered one-shot extraction entry, save/load coverage, and clear text if it stores only card ids rather than full card snapshots.
- `URDA-ROOT-EYES-PREVIEW-REDESIGN`: current source auto-marks the next reachable non-Boss node and can spend below zero. The redesigned interaction must only target Monster / Unknown or Event / Elite nodes, consume exactly one eye, persist the preview by coord, show the rolled preview on hover, and exclude RestSite / Shop / Treasure / Boss.
- `MORVI-BLUEPRINT-PROOF-NO-EFFECT`: add source-level hook tests for manual first-in-series card plays and add live debug logging for selected blessing state, eligibility failure reason, `IsFirstInSeries`, `IsAutoPlay`, and deck ownership. If `DeckVersion` is unreliable in live play, replace that eligibility check with a source-backed owned-card test.
- `VAKUU-ENTRY-PRIMAL-CLAW`: before exposing the fight by default, collect live evidence for victory return, failure/death, active-fight save/load, event restoration, and no-normal-reward return. Player-facing text or setup instructions must explain the enable/force gates used for test builds.
- `URDA-ROOTED-ROUTE-MP-RESEARCH`: multiplayer rules must be decided before code changes. Acceptable directions to choose from are multiplayer-disabled, party-wide target, host/leader-owned target, or no individual punishment unless the party route satisfies the player target.
- `MORVI-MISPRINTED-PRESS-TEXT`: text should state the actual source behavior: each turn, the first manually played natural-deck Attack or Skill is played one extra time; if that triggering card's base cost is at least 1, draw 1 after the final resolution. Exclusions include Powers, Statuses, Curses, autoplay, and generated cards.
- `MORVI-DEBT-WORDING`: event text must expose the same 320 / 40 / 3 numbers as the hover: gain 220 Gold, record 320 debt, repay 40 after each combat, and lose 3 nonlethal HP per missing 10 Gold, rounded up.
- `URDA-MOSS-MAP-TEXT`: compact mapping must name all five room rewards in source order: Monster +25 Gold; Event heal 5; Shop gain a Potion; Elite upgrade 1 random card; Rest Site +3 Max HP.
- `MORVI-FORBIDDEN-LOAN-TEXT`: event description should start from the player benefit, `获得 1 张已升级远古牌` / `Choose and add 1 upgraded Ancient card`, then explain HP-on-play and the Act 2 Boss 180 Gold retain-or-remove settlement.

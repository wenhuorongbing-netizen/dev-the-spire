# Feature Input Archive

`docs/archive/feature-inputs/` preserves historical feature prompts, superseded implementation specs, and old source-design inputs that should not stay inside active feature folders.

Current development should start from `docs/README.md`, `docs/test-ready-development-goal.md`, `docs/issues.md`, and the active feature README files. Use these archived inputs only for traceability when investigating old decisions.

- `ascension-11-20/`: historical Ascension implementation prompt/spec records. Current Ascension guidance remains in `docs/features/ascension-11-20/`.

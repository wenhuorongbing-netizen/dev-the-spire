# Ancient Expansion v2.2 Risk Register

Status: Urda, Morvi, and Lotha are default-on/source-backed for private-beta testing, including Urda's full ten-blessing v2.2 set. Vakuu fight is hidden by default with a dedicated source enemy/scene plus Contract, Stolen Vault, and Blood Debt pressure because it still needs live post-victory proof. Vakuu now uses a direct parent-room stack transition, explicitly clears the parent event node before child combat, avoids active `ParentEventId` serialization, records the parent only for prefinished restore, and skips the duplicate Ancient heal during prefinished parent restore. Lotha now persists Death Reprieve phase through deck-mirrored state, but all live save/load/co-op risks remain open until verified or explicitly accepted. Do not make a release-ready claim.

# Spire Plus 简介

`Spire Plus` 是一个 Slay the Spire 2 私测模组。玩家只需要启用这一个模组；稳定技术 id 和安装目录仍是 `EZMicroBalance`。

## 当前内容

- 先古之民奖励重做，并用可见遗物显示已选择的奖励。
- 进阶 11-20 私测路线，包括更宽的地图、火印精英、根芽/根蚀、战旗房、王印和王烙印。
- Urda、Morvi、Lotha 的奖励切片。
- 隐藏开关控制的 Vakuu 战斗切片。
- 水晶球预见和变换预览工具，已并入同一个 `Spire Plus` 模组。

## 不包含

- A21-A30。
- 自定义角色。
- 单独的 `Future Peek` 模组。
- 旧 `EzDailyContent` 发布入口。

## 测试状态

当前目标是 test-ready 手动测试包。自动化构建、测试和包体检查可以证明源码、资源和包体一致；实机玩法、save/load、死亡/失败路径和联机仍需要手动验证。

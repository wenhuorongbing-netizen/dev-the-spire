# EZ Micro Balance 简介（网页版）

## 1. 这个Mod是做什么的

`EZ Micro Balance` 是一套聚焦于 **Ancient 奖励再平衡** 的私测模组，核心目标是保留游戏主线节奏的同时，让单局体验更可读、更可控、更可验证。  
它是从 `EzDailyContent` 分离出来的独立模组，公开 ID 为 `EZMicroBalance`。

### 版本边界

- 依赖游戏源码：`Slay the Spire 2 v0.105.0`
- 依赖基础库：`BaseLib v3.1.2`
- 作用范围：`Ancient` 奖励重制 + `Ascension 11-20` 试验路径
- 不在本周期实现：`A21-A30`、自定义角色、与主系统大改动相关的功能

## 2. 我们为什么改这些

1. 让 Ancient 系列的战斗反馈更清晰，减少“看得懂”和“会不会影响下一局不明确”的问题。
2. 把高阶登天（Ascension 11-20）从“看起来有变化但缺少反馈”改成“可复现、可验证的规则差异”。
3. 兼顾单机和联机，不把联机问题误当成文档完成。
4. 建立可长期维护的文档和验证链路，避免后续每次修复都在旧结论上打转。

- 处理 `Fission` 在高登天下稀有度衰减过快的问题。

- `Rootblight I/II/III`、`Blight Sprout` 文案统一官方式可读性结构。
- 去除重复显性关键字（如已经存在 `CanonicalKeywords` 的情况下再写 `Play: Exhaust`）。
- 添加卡片预览（hover tip）并补齐术语高亮。
- `Rootblight` 与 `Blight Sprout` 的添加/进化反馈改为可见提示。
- 补充卡面资源（generated portrait）并接入打包链路。

#### A20 多人与警戒

- 允许多人选择 A11-A20 的公开开关路径保留可控能力。
- 对 A20 多人场景加入日志/提示区分，避免将仅在单机验证通过的玩法误展示为多人已支持。

## 4. 可读性与可用性（你要求的重点）

### 4.1 文案规范采用源码风格

详见 [docs/style/card-localization-style-guide.md](style/card-localization-style-guide.md)。  
核心点如下。

- 已有关键字请不要重复写入描述文本。
- 重要名词、卡名、牌堆名使用 `[gold]...[/gold]` 高亮。
- 数值使用可变参数表达，避免硬编码。
- 任何“新增/进化/放入牌堆”类文本都应有卡片预览机制。
- 英文与简中行为保持一一对应，不出现规则歧义。

### 4.2 术语固定（与游戏文本保持一致）

- `Rootblight` 保持为 `Rootblight`/`根蚀`
- `Root Bud` / `Blight Sprout` 对应 `Blight Sprout / 根芽`
- `Draw Pile` 使用 `Draw Pile / 抽牌堆`
- `Discard Pile` 使用 `Discard Pile / 弃牌堆`
- `Exhaust Pile` 使用 `Exhaust Pile / 消耗牌堆`
- `Deck` 使用 `牌组 / 主牌组`（按源码上下文区分）

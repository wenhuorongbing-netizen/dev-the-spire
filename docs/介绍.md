# Spire Plus 简介

`Spire Plus` 是一个 Slay the Spire 2 私测模组，稳定 manifest id 为 `EZMicroBalance`。玩家只需要启用这一个模组。

## 当前范围

- Ancient 奖励重做与可见遗物奖励。
- Ascension 11-20 私测路线。
- 根芽、根蚀、战旗房、火印精英、首领王印与王烙印。
- 水晶球预知按钮与变换预览工具，已并入 `Spire Plus`。

## 不包含

- A21-A30。
- 自定义角色。
- 单独的 `Future Peek` 模组。
- 旧 `EzDailyContent` 发布入口。

## 测试状态

当前目标是 test-ready。自动化构建、测试和包体检查可以证明源码与资源一致，但 live gameplay、save/load、死亡路径和联机仍需要手动验证。
